# Role 6 – API and Dashboard

## API
Customer Churn & LTV Prediction API implemented using FastAPI.

### API Endpoints
- GET / – API status
- GET /health – Health check
- POST /predict – Single customer churn prediction
- POST /batch_predict – Batch customer predictions

## Dashboard
Metabase dashboards:
- Churn & LTV Overview
- Churn Risk
- LTV Segmentation

## Technologies
- FastAPI
- Docker
- PostgreSQL
- Metabase
